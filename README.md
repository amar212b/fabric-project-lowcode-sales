# \# Sales Analytics (Microsoft Fabric)

# 

# 

# \*\*Business Problem:\*\* Small project to use different features available in Fabric to Analyze sales data 

# 

# \*\*Dataset:\*\* Superstore Sales CSV (Kaggle – simplified sales data)

# 

# \*\*Key Features Implemented:\*\*

# \- \*\*Dataflow Gen2\*\*: Low-code ingestion, filtering (Sales > 0), type changes, derived columns

# \- \*\*Shortcuts\*\*: Zero-copy external reference (public ADLS Gen2 demo)

# \- \*\*Invoke Pipeline\*\*: Orchestrated end-to-end flow

# \- \*\*Warehouse\*\*: SQL analytics endpoint + semantic model

# \- \*\*DAX Measures\*\*: Total Sales, Average Sales, High Value Orders, Sales YoY Growth, Profit Proxy

# \- \*\*Power BI Dashboard\*\*: Visual insights (bar charts, slicers)

# 

# \*\*Note\*\*: Built in Fabric trial capacity (some UI options limited; Warehouse used when available).

# 

# \*\*Portfolio note\*\*: All steps manual export (Git sync disabled in trial).
